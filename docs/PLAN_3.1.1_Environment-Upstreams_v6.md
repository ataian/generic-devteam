**Goal:** Give a generated team two independent capabilities: work on the current checkout with `dev-environment`, and deliver a requested local disposable demo with usable logins after development.

**Architecture:** The Maker owns skill acquisition, role assignments, planning decisions, card dependencies, review scope and customer contact. The installed upstreams own project discovery, generated files, launchers, runtime operations and scoped command grants. Keep project-specific commands in the generated project guides, not in role SOULs or every ticket.

**Technology:** Existing Python renderer/updater and unittest suite; manifest-driven external acquisition; upstream Bash/Python/Compose launchers. No new orchestrator, password store, Docker grant framework or mandatory team setup smoke run.
