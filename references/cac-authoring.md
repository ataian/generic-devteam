# Compact artifact contract

Write the shortest version that lets the recipient take the same action, for the same reason, within the same authority. If shortening would change a decision or hide a risk, keep the explanation.

- For recurring agent exchanges, use the compact form at the writing step. A labeled line suits one event; group related facts in bullets. Use a sentence for a condition, sequence or consequence that labels obscure. Omit empty fields, not required negative results. Examples are not exhaustive schemas.
- Preserve the actor, trigger, obligation, order, exceptions, scope and failure exit. Keep exact commands, identifiers, paths, literals, numbers and units. Required, optional, unknown and absent are distinct: “required, non-null” rejects both missing and null. A valid zero is not missing.
- State what was observed, by whom and on which revision. Keep limitations, uncertainty and unresolved decisions beside the claim. A pointer replaces detail only if the recipient can retrieve the exact evidence and identify the applicable state. Written, tested, independently reviewed, approved and deployed are different claims.
- Keep durable authority in the role instructions; put a procedure at its existing point of use. Change the owning clause rather than adding a second version. Move it only to a source the intended recipient loads in that context, including after resume.
- Write internal development text in plain technical English. Match human-facing conversation and documentation to their reader. In generated teams, only the Planner writes for the customer; Coder, Codex and Reviewer write for the team in English. Explain consequential choices and warnings in ordinary sentences. Preserve quotations, localized text, project code conventions and formal output contracts.

**Fidelity check:** Compare the original and revised instructions for an ordinary case and the failing or exceptional case. Can a fresh recipient recover the same action, authority, evidence and next step without guessing? Restore any missing distinction before counting savings.
